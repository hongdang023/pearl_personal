# 4.2 Do / Don't: Mentor Anti-patterns

Thuộc [4 · Question Bank & Anti-patterns](/mentor-guidelines/).

## Bảng tra cứu Anti-patterns

| Don't (Nên tránh) | Do (Nên làm) |
| :--- | :--- |
| ❌ Cầm chuột / gõ code làm hộ học sinh | ✅ Giúp học sinh nhìn thấy khoảng trống (Gap) |
| ❌ Hỏi "Em có hiểu không?" | ✅ Hỏi "Em đã thử cách nào rồi?" |
| ❌ Thấy học sinh kẹt → Đưa ngay đáp án | ✅ Diagnose xem học sinh kẹt ở đâu trước |
| ❌ Chạy theo tiến độ hoàn thành Product | ✅ Tìm kiếm bằng chứng học tập (Learning Evidence) |
| ❌ Thấy im lặng → Kết luận học sinh chán | ✅ Quan sát thêm 3 phút xem học sinh có đang suy nghĩ không |
